# MUSE

좋아하는 연예인 사진 5장으로 내 취향의 가상인물을 만들고, 그 인물로 사진·영상을 계속 만드는 앱이에요.

- 유료 버전 (Gemini API 키 사용): https://double-hee.github.io/muse/
- 무료 버전 (Pollinations · Hugging Face): https://double-hee.github.io/muse/free/

만들어진 인물은 실존하지 않는 가상인물이에요. 실존 인물을 사칭하거나 오해를 부르는 용도로는 쓰지 말아 주세요.
